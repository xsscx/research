sRgbEncoding.icc

A 160-byte ICC.2/v5 color-encoding profile reduced to the bare skeleton: 128-byte header, one tag table entry, one UTF-8 payload, and several deliberate conformance gaps. The layout is modeled after corkami's binary posters: bytes on the left, meaning on the right.

Structure

  • 0x000-0x07F is the fixed 128-byte ICC header.
  • 0x080-0x083 stores the tag count as a big-endian uint32.
  • 0x084-0x08F is the only tag directory entry: signature, offset, size.
  • 0x090-0x09C holds the tag body. The file ends at 0x09F after alignment padding.
  • The profile is intentionally tiny enough that the entire object fits on one poster without truncation.

Why This Is A Good Poster Sample

  • It is small enough that every byte can be shown on one page without scrolling through a large LUT.
  • It still exercises the ICC skeleton: header, tag count, tag entry, tag type, payload, and padding.
  • The non-zero bytes are sparse, which makes spec violations obvious at a glance.
  • It demonstrates the gap between a minimally parseable binary object and a conformant, production-ready ICC profile.
