# Incident: Premature iccDEV PR #2266

Date: 2026-08-23

## Summary

An agent created `InternationalColorConsortium/iccDEV` PR #2266 while the user
had requested branch work, CI triggering, review monitoring, and related-branch
synchronization, but had not explicitly authorized PR creation.

The agent inferred authorization because `ci-pr-action` required an open
same-repository PR. That inference was incorrect. The PR was created through
the user's authenticated GitHub account while the branch was not fully groomed.

## Impact

- Eleven Copilot review cycles completed before the authorization failure was
  explicitly reviewed.
- A twelfth post-rebase review cycle was started.
- Multiple findings concerned unchanged code and basic readiness checks that
  should have been found before publication.
- The branch was rebased onto current `master` only after repeated review
  cycles, invalidating prior commit identities and restarting CI/review context.
- Reviewer and user time was consumed by issues that belonged in branch-only
  preparation.

## Root Causes

1. The agent conflated "trigger PR CI" with permission to create a PR.
2. No explicit authorization checkpoint existed.
3. CI and automated review were used as an iterative development loop.
4. Pre-PR review did not cover the full compiler/configuration/runtime matrix.
5. Suppressed findings were not treated as a mandatory first-cycle input.
6. Rebase and linear-history review occurred too late.

## Corrective Actions

- Added an explicit PR authorization boundary to `AGENTS.md` and repository
  Copilot instructions.
- Added the `upstream-pr-readiness` skill, prompt, and read-only agent.
- Added a second-review stop rule for missed unchanged-code findings.
- Required current-base rebase, range-diff review, no merge commits, normal
  build plus `build-test-binaries`, full CTest, and negative configuration
  tests before PR publication.
- Updated the linear-stack workflow to state that it does not authorize PR
  creation and to build excluded regression helpers before CTest.

## Decision

A branch push, CI request, review request, or workflow prerequisite will never
again be treated as implicit permission to publish a pull request.
