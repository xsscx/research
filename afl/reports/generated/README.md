# Generated AFL Reports

This directory is the default runtime output root for AFL report, coverage,
stats, and UI assets generated by the scripts in `afl/`.

Generated report payloads are intentionally ignored by git because they can
include coverage HTML, profiler output, AFL queues, minimized corpora, logs,
and temporary build trees. Keep durable findings in `afl/reports/` as checked-in
Markdown summaries.

`latest` is a local symlink maintained by `afl/report.sh`, `afl/coverage.sh`,
and `afl/report-ui.sh`. It points at the most recently generated or served
report directory and is ignored by git.

There is no `afl/report/` directory. Use:

```bash
./afl/report.sh all --no-coverage
./afl/report.sh all --jobs 2 --target-timeout 3600
./afl/report-ui.sh afl/reports/generated/afl-report-YYYYMMDDTHHMMSSZ
```

Reports produced in external session directories, such as `~/work/copilot`, can
be viewed without copying them:

```bash
./afl/report-ui.sh /home/h02332/work/copilot/afl-report-stats-validation-20260702T0940
```

The launcher exposes external reports through ignored
`afl/reports/generated/external-*` symlinks so the static browser viewer can
fetch `status.json`, `targets.tsv`, coverage HTML, plots, and notes from one
local HTTP root.
