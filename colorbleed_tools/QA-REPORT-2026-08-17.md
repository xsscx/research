# ColorBleed Tools Cross-Check Report

Date: 2026-08-17

## Result

PASS. All seven ColorBleed tools built and completed the release, debug, and
sanitizer cross-check against upstream iccDEV `3e348201` (`2.3.2.3+3e34820`).
All 42 measured tool invocations returned zero. No ASan or UBSan finding was
detected.

## Validation and TIFF Results

Both XML- and JSON-returned profiles reported:

```text
Profile is valid for version 4.20
```

The TIFF tool extracted 60,960 bytes from the tracked fixture. The extracted
profile was byte-identical to the source ICC and validated successfully.

A separate depth-512 nested-profile check exercised the upstream recursive
`ReadTags()` bound added in `3e348201`. The tool preserved all 77,956 embedded
ICC bytes, returned the expected soft parser status 5, did not time out, and
reported no sanitizer finding.

## Reproduction

```bash
cd /home/xss/research
colorbleed_tools/build.sh all
.github/scripts/colorbleed-crosscheck.sh
```

The cross-check writes generated ICC, XML, JSON, comparison, metric, and log
files to a temporary output directory. Pass an explicit third argument to keep
results at a chosen external path. It does not place generated test output in
the repository.

## Boundaries

This report proves deterministic round-trip behavior for the checked-in sRGB
TIFF/ICC fixture and bounded behavior for the nested-profile stress case. It is
not a claim that every profile in the research corpora round-trips without a
representation delta.
