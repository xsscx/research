================================================================================
WHAT THE LUT VISUALIZATION DOES
================================================================================

1. VISUALIZES 1D TONE CURVES (TRC Tags)
   - Renders Red/Green/Blue/Gray tone reproduction curves
   - Samples curves at 1000+ points
   - Draws in SVG format with coordinate axes and labels
   - Supports: Curve, ParametricCurve, SegmentedCurve types

2. VISUALIZES 3D/ND LOOKUP TABLES (AToB/BToA Tags)
   - Extracts input curves (curveA), output curves (curveB), matrix curves (curveM)
   - Visualizes each curve in SVG
   - Exports CLUT grid data as TIFF images
   - Supports: Lut8, Lut16, LutAtoB, LutBtoA tags

3. EXPORTS DATA TO TWO FORMATS
   - SVG: Vector graphics, curves with axes, titles, descriptions
   - TIFF: Raw CLUT grid data as raster images (8/16/32/64-bit)

4. PROVIDES SAFETY GUARANTEES
   - Path validation (no "..", no system dirs, symlink resolution)
   - Integer overflow checks (SafeMul2/3/4 functions)
   - Memory limits (256MB single alloc, 1GB total)
   - Process isolation (fork-based sandboxing on Linux)
   - Signal recovery (SIGSEGV/SIGBUS/SIGFPE/SIGILL via siglongjmp)
   - XML escaping (prevent XSS in SVG output)

TIFF TECHNICAL DETAILS
================================================================================

File Header (8 bytes):
  Bytes 0-1: Byte order indicator (II=0x4949 or MM=0x4D4D)
  Bytes 2-3: Magic number (0x002A = 42)
  Bytes 4-7: Offset to first IFD (usually 8)

IFD Structure (15 tags, 12 bytes each):
  Tag Count (2 bytes)
  [For each tag]:
    Tag ID (2 bytes)
    Type (2 bytes) - SHORT/LONG/RATIO/FLOAT/etc
    Count (4 bytes) - number of values
    Value/Offset (4 bytes) - value if ≤4 bytes, offset if larger

Data Section:
  BitsPerSample array (if channels > 1)
  Resolution ratios (XResolution, YResolution)
  Strip offset/byte count arrays (for future use)
  Pixel data (uncompressed, interleaved)

Special Features:
  ✓ CIELAB data: a*/b* shifted to signed [-127,127] (8-bit) or [-32767,32767] (16-bit)
  ✓ Float support: 32-bit and 64-bit IEEE 754 via TIFF_SAMPLE_FORMAT=FLOAT
  ✓ Endianness: Auto-detected from platform (getBigEndian)
  ✓ Compression: NONE (uncompressed)
  ✓ Tiling: None (strip-based, single strip per image)
