Every heuristic contains 5 layers of identical boilerplate:
  1. Entry:     int heuristicCount = 0;
  2. Label:     printf("[H##] Name\n");
  3. Resource:  RawFileHandle/CIccProfile open
  4. Loop:      Tag enumeration (85% identical)
  5. Report:    if (count > 0) printf("[WARN]") else printf("[OK]")
  6. Exit:      printf("\n"); return heuristicCount;

Result: 70% of code is duplicated patterns; only validation differs.
