2. DATA FLOW - processLuts() COMPLETE SEQUENCE
================================================================================

1. INITIALIZE
   └─ Determine basename (remove .icc/.icm)
   └─ Validate output paths (no "..", no system dirs, parent resolvable)

2. CREATE SVG
   └─ SVGOut svgfile(svgPath)
   └─ WriteHeader(0,0 to 203.2mm, 203.2mm) [8"×8"]

3. ITERATE TAGS
   ├─ 1D TRC Tags: icSigRedTRCTag, icSigGreenTRCTag, etc.
   │   └─ output1DLUT() → describe1DLUT() + graph1DLUT() → SVG
   │
   └─ 3D LUT Tags: icSigAToB0Tag, icSigBToA0Tag, etc.
       └─ output3DLUT():
           ├─ Get CIccMBB (Lut8/16/AtoB/BtoA)
           ├─ Process curves A, B, M via output1DLUT()
           └─ Process CLUT:
               ├─ clut->Begin() [grid info]
               ├─ Get dimensions: GridPoints(), GridPoint(1/2)
               ├─ Calculate tiling (square-ish grid)
               ├─ Allocate buffer: SafeMul4(tiles, w, h, channels)
               ├─ Copy CLUT to image buffer
               │   inputIndex = z*n001 + y*n010 + x*n100
               │   outputIndex = z3*outTileStepV + z2*outTileStepH + ...
               └─ WriteTIFF(basename + "_" + tag + ".tif")

4. CLOSE SVG
   └─ svgfile.CloseFile()

7. INVOCATION
================================================================================

Command:
  iccDumpProfile <profile.icc> LUTS

On Linux (with sandbox):
  ├─ Parent calls RunSandboxed()
  ├─ Child fork() with resource limits + signal handlers
  ├─ Child: processLuts() → creates output files
  ├─ Parent: waits, reports exit status/signals
  └─ Output: SVG + TIFF files

On Windows (no sandbox):
  └─ Direct call: processLuts() → output files

Output files:
  <profile>_luts.svg
  <profile>_AToB0Tag.tif (if AToB0 exists)
  <profile>_BToA0Tag.tif (if BToA0 exists)
  ... (one TIFF per LUT tag)

8. TIFF FILE STRUCTURE EXAMPLE (RGB, 256×256, 8-bit)
================================================================================

Offset 0x00: "II" (little-endian marker)
Offset 0x02: 0x002A (magic 42)
Offset 0x04: 0x00000008 (IFD offset)

Offset 0x08: 0x000F (15 IFD entries)
Offset 0x0A-0xD7: IFD entries (12 bytes each)
  Tag 256 (WIDTH): LONG, 1, 256
  Tag 257 (HEIGHT): LONG, 1, 256
  Tag 258 (BITSPERSAMPLE): SHORT, 3, offset to [8,8,8]
  Tag 259 (COMPRESSION): LONG, 1, 1 (none)
  Tag 262 (INTERPRETATION): LONG, 1, 2 (RGB)
  Tag 273 (STRIPOFFSETS): LONG, 1, [offset to pixel data]
  Tag 277 (SAMPLESPERPIXEL): LONG, 1, 3
  Tag 278 (ROWSPERSTRIP): LONG, 1, 256
  Tag 279 (STRIPBYTECOUNTS): LONG, 1, [size]
  Tag 282 (XRESOLUTION): RATIO, 1, [offset to 100000/1000]
  Tag 283 (YRESOLUTION): RATIO, 1, [offset to 100000/1000]
  Tag 284 (PLANARCONFIG): LONG, 1, 1
  Tag 296 (RESOLUTIONUNIT): LONG, 1, 2 (inches)
  Tag 317 (PREDICTOR): LONG, 1, 1 (none)
  Tag 339 (SAMPLE_FORMAT): LONG, 1, 1 (unsigned)

Offset 0xD8+: 0x00000000 (next IFD = none)

Offset [bits_offset]: 08 08 08 (BitsPerSample array)
Offset [xres_offset]: 00 01 86 A0 / 00 00 03 E8 (100000/1000)
Offset [yres_offset]: 00 01 86 A0 / 00 00 03 E8 (100000/1000)

Offset [stripOffset]: RGB pixel data (256×256×3×1 = 196608 bytes)
  R0G0B0 R1G0B0 ... R255G0B0
  R0G1B0 R1G1B0 ... R255G1B0
  ...
  R0G255B0 R1G255B0 ... R255G255B0

9. SAFETY CHECKS IN CLUT DATA COPY (lines 1275-1352)
================================================================================

Before buffer allocation:
  ✓ tiles > 0, tileWidth > 0, tileHeight > 0
  ✓ outputChannels > 0, bytes > 0
  ✓ SafeMul4(tiles, tileWidth, tileHeight, outputChannels, clutSize)
  ✓ SafeMul4(imageWidth, imageHeight, outputChannels, bytes, bufferSize)
  ✓ clutSize ≤ clut->NumPoints() * outputChannels

During copy loop:
  ✓ For float samples: filter NaN/Inf to 0.0
  ✓ For 16-bit quantization: clamp [0,1] to [0,65535]
  ✓ For 8-bit quantization: clamp [0,1] to [0,255]

After write:
  ✓ Check WriteTIFF() return value
  ✓ Report filename and error status
